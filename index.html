Deep Learning for Triaging Normal Breast MRI

An open-source project to train and test a deep learning model for triaging normal breast MRIs to an abbreviated list, with applications in adaptive scanning to reduce scan times.

Get Docker Image See Workflow

Core Components

The triage system is built on a two-stage deep learning pipeline for robust analysis of MRI scans.

2D U-Net Segmentation

A U-Net model segments the breast from the thorax in subtracted Maximum Intensity Projection (MIP) images.

VGG-16 Classification

A VGG-16 network classifies segmented breasts as "less suspicion" or "highly suspicion" based on BI-RADS categories.

Automated Pipeline

The entire testing process is automated, taking raw DICOM files as input and producing a model prediction.

Dockerized Inference

A Docker image is available to easily run the inference pipeline without complex setup or dependency issues.

Project Workflow

The project is separated into distinct training and testing pipelines, each with a clear, automated workflow.

Training Pipeline

The training process starts with subtracted MIP images which are fed into a 2D U-Net to produce a binary mask of the breast. This mask is used to segment the breast region.

The segmented images are then split into left and right breasts and passed to a VGG-16 binary classifier. The classifier is trained using BI-RADS categories to distinguish between low-suspicion and high-suspicion cases.

Testing & Inference Pipeline

The testing pipeline is fully automated. It takes DICOM files as input and generates four subtracted MIPs. These MIPs are processed by the trained U-Net for segmentation.

The resulting segmented breasts are then classified by the trained VGG-16 model to generate a final prediction. The process also supports Grad-CAM visualization to interpret model decisions.
